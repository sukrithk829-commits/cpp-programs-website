💻 Download Programs Using Terminal

🎯 Quick Download (Single Program)

Download any single program directly to your local machine using one command:

# Example: Download hello_world.cpp curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp # Example: Download variables.cpp curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/variables.cpp # Example: Download loops.cpp curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/control_flow/loops.cpp
# Using PowerShell (Windows 7+) Invoke-WebRequest -Uri "https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp" -OutFile "hello_world.cpp" # Or using curl (Windows 10+) curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp # Or using wget (if installed) wget https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp
💡 Pro Tip: Copy the "Copy Terminal Command" button on any program card above to copy the exact download command!

📋 Program URL Structure

All programs follow this URL pattern:

https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/CATEGORY/program_name.cpp

Replace:

  • CATEGORY = basics, control_flow, algorithms, oop, data_structures
  • program_name.cpp = the actual program file name

🚀 Full Workflow Example

  1. Open terminal/command prompt on your local machine
  2. Create a folder for your programs:
    mkdir my_cpp_programs cd my_cpp_programs
  3. Download a single program using curl:
    curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp
  4. Compile the program:
    g++ -o hello hello_world.cpp
  5. Run the program:
    ./hello # Linux/Mac hello.exe # Windows

📥 Download Multiple Programs at Once

Linux/Mac:

# Download multiple files curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/variables.cpp curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/control_flow/loops.cpp # Or using a loop to download all from a category for file in hello_world variables; do curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/$file.cpp done

Windows (PowerShell):

# Download multiple files @("hello_world", "variables") | ForEach-Object { Invoke-WebRequest -Uri "https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/$_.cpp" -OutFile "$_.cpp" }

🔄 Update Programs (Pull Latest Version)

If a program has been updated on GitHub, download it again:

curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/basics/hello_world.cpp

The new version will replace the old one.

📝 How to Add Your Own Programs

✨ Method 1: Add via GitHub Website (Easiest)

  1. Click the "+ Add New Program" button in any category above
  2. GitHub will open a file creation page
  3. In the filename field, enter: program_name.cpp
    Example: prime_numbers.cpp, fibonacci.cpp, etc.
  4. Paste your C++ code in the editor
  5. Scroll down and click "Commit changes"
  6. Done! Your program is now available for download

💻 Method 2: Add via Terminal (Git Clone)

  1. Clone the repository:
    git clone https://github.com/sukrithk829-commits/cpp-programs-website.git cd cpp-programs-website
  2. Create your program file:
    nano algorithms/prime_numbers.cpp
  3. Write your C++ code and save
  4. Push to GitHub:
    git add algorithms/prime_numbers.cpp git commit -m "Add prime_numbers.cpp - Find primes from 1 to 100" git push origin main

📌 Naming Guidelines

  • Use lowercase with underscores: prime_numbers.cpp
  • Be descriptive: fibonacci_sequence.cpp (not just fib.cpp)
  • Place in correct folder: algorithms, basics, oop, etc.
