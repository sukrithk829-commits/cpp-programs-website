⬇️ How to Download Programs

📖 Download URL Format

All programs follow this pattern:

https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/FOLDER/PROGRAM_NAME

Replace:

  • FOLDER: cpp, webprogramming, or rdbms
  • PROGRAM_NAME: the actual file name you want

💻 Terminal Download Commands

Windows (Command Prompt / CMD)

Note: curl ships built into Command Prompt on Windows 10 (version 1803+) and Windows 11, so no extra install is needed. Just open cmd and run the commands below.

Download from cpp/ folder:

curl -o hello_world.cpp https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/hello_world.cpp

Download from webprogramming/ folder:

curl -o calculator.html https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/webprogramming/calculator.html

Download from rdbms/ folder:

curl -o create_table.sql https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/rdbms/create_table.sql

Download multiple programs at once:

curl -o hello_world.cpp https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/hello_world.cpp curl -o prime_numbers.cpp https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/prime_numbers.cpp curl -o fibonacci.cpp https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/fibonacci.cpp

Download from webprogramming/ folder:

🚀 Complete Workflow

For C++ Programs (Linux/Ubuntu)

  1. Create a folder:
    mkdir my_programs cd my_programs
  2. Download:
    curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/hello_world.cpp
  3. Compile:
    g++ -o hello hello_world.cpp
  4. Run:
    ./hello

For C++ Programs (Windows)

  1. Create a folder and navigate:
    mkdir my_programs cd my_programs
  2. Download (Command Prompt):
    curl -o hello_world.cpp https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/cpp/hello_world.cpp
  3. Compile:
    g++ -o hello hello_world.cpp
  4. Run:
    hello.exe

For Web Programming

  1. Download (Linux/Ubuntu):
    curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/webprogramming/calculator.html
  2. Open in browser: Double-click the .html file
  3. Edit: Open with any text editor (VS Code, Notepad++, nano, etc.)

For RDBMS/SQL

  1. Download (Linux/Ubuntu):
    curl -O https://raw.githubusercontent.com/sukrithk829-commits/cpp-programs-website/main/rdbms/create_table.sql
  2. Run in database client: MySQL Workbench, pgAdmin, SQL Server Management Studio, etc.
  3. Execute the SQL query in your database management tool
