🛠️ How to Use This Repository

Clone the Repository

  1. Open your terminal/command prompt
  2. Navigate to where you want to store the files
  3. Run the clone command:
git clone https://github.com/sukrithk829-commits/cpp-programs-website.git

Compile and Run a Program

  1. Navigate to the program folder
  2. Compile the C++ file:
g++ -o output_name program_name.cpp
  1. Run the compiled program:
./output_name # On Linux/Mac output_name.exe # On Windows

Update Your Local Repository

git pull origin main
